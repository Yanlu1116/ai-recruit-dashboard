## 邮箱自动导入实习生简历功能

- 需求: Dashboard 中可自动搜索邮箱里含「实习/秋招/求职/intern」关键词的简历并导入分析
- 架构: Python Flask 后端桥接 (localhost:8089) + 前端弹窗交互

### 新增/修改文件:
1. **server.py** (新建): Flask 后端，提供 REST API
   - `/api/search-emails` — 按关键词搜索邮箱 (当前读缓存)
   - `/api/batch-import` — 批量下载+解析 PDF/DOCX → 返回纯文本
   - `/api/update-cache` — 接收 WorkBuddy 推送的邮箱搜索结果
   - `/api/cache-status` — 缓存状态查询
   - 含 `--generate-demo` 模式生成 5 份模拟实习生简历数据
2. **index.html** (+~60行): 新增「从邮箱导入」按钮区域 + 完整的搜索弹窗 UI
3. **styles.css** (+~250行): 邮箱导入按钮、弹窗、搜索结果列表、进度指示器全套样式
4. **app.js** (+~180行): openEmailImport / search / batch-import / progress UI / close 全流程

### 使用流程:
1. 在步骤2「上传简历」页面，点击「从邮箱自动导入实习生简历」
2. 弹窗自动调用 `/api/search-emails` 搜索匹配邮件
3. 勾选要导入的简历 → 点击导入
4. 后端解析附件为纯文本 → 自动加入简历列表 → 可点击「开始智能分析」

### 缓存机制:
- 演示数据: `python server.py --generate-demo`
- 真实数据: WorkBuddy 通过 agent-mail MCP 搜索邮箱 → 调用 `/api/update-cache` 更新
- 缓存目录: `.email_cache/`
