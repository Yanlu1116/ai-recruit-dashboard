## 2026-07-30

### 添加国金证券 POP3 邮箱预设
- 后端 `server.py` 新增 `gjzq` 预设：服务器 `email.gjzq.com.cn`，端口 110，无 SSL，仅支持 POP3
- 前端 `index.html` 下拉菜单新增「国金证券邮箱 (POP3)」选项
- 前端 `app.js` 选择该预设时自动锁定 POP3 协议、禁用 IMAP 选项、显示对应提示文字
- 已推送到 GitHub，Render 将自动部署

### 邮箱搜索关键词改为手动输入
- 连接邮箱后不再自动搜索，弹出关键词输入面板
- 默认填入 `intern, 实习, 秋招, 求职`，用户可自由修改
- 支持逗号或空格分隔多个关键词，按回车或点击按钮搜索
- 新增「返回修改邮箱配置」按钮，可随时更换邮箱账号
- 新增 `.email-keyword-panel` / `.email-keyword-hint` CSS 样式

### 修复关键词面板被遮挡 bug
- `saveEmailConfig` 成功后同时显示配置面板和关键词面板导致遮挡
- 修复：成功后 0.8 秒自动隐藏配置面板，切换到关键词面板

### 修复 POP3 连接「Protocol error」
- 根因：`conn.getwelcome()` 调用多余 — `poplib.POP3()` 构造函数已自动读取欢迎标语，二次读取在 CoreMail 上触发协议错误
- 修复：移除 `getwelcome()` 调用
- 新增自适应登录：先尝试完整邮箱地址，失败后自动尝试纯用户名（@之前部分）
- 新增分步错误追踪：错误信息现在会明确显示失败在 USER/PASS/STAT 哪个步骤

### 修复 POP3 搜索找不到邮件
- 根因：`TOP n 0` 命令在部分内网 POP3 服务器（如 CoreMail）上可能不被支持或行为异常
- 修复：改用 `RETR` 获取完整邮件内容来解析 header，兼容性更好
- 默认只搜索最近 50 封邮件，避免全量扫描太慢
